# StudentInsight AI — REST API Documentation
**Student Performance & At-Risk Prediction**
*Algions AI Labs Private Limited — AI & Machine Learning Assessment*

Base URL: `http://localhost:8000`  
Interactive Swagger UI: `http://localhost:8000/api/docs`  
Interactive ReDoc: `http://localhost:8000/api/redoc`

---

## Endpoints Summary

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/api/health` | Health status and model loading readiness |
| `GET` | `/api/dashboard/summary` | Cohort-wide metrics derived from actual data |
| `GET` | `/api/students` | Filtered, sorted, paginated student records |
| `GET` | `/api/students/{student_id}` | Longitudinal history and trajectory for a single student |
| `POST` | `/api/predict` | Real-time advisory risk prediction via trained pipeline |
| `GET` | `/api/analytics/performance-trends`| Mean assessment scores, attendance, and at-risk rates over time |
| `GET` | `/api/analytics/attendance` | Attendance distribution brackets and correlated failure risk |
| `GET` | `/api/analytics/assignment-completion` | Homework completion rates and correlated failure risk |
| `GET` | `/api/analytics/risk-distribution` | Distribution across Low, Medium, and High advisory risk bands |
| `GET` | `/api/model/metrics` | Empirical validation and test metrics comparing all models |
| `GET` | `/api/data/preview` | Paginated preview of the dataset and column schema audit |

### 3. Student Records Listing
- **Method**: `GET`
- **Path**: `/api/students?page=1&page_size=20&risk_band=High&search=STU`
- **Query Parameters**:
  - `search` (string, optional): Search by anonymous Student ID prefix/substring.
  - `risk_band` (string, optional): `ALL`, `High`, `Medium`, or `Low`.
  - `period` (int, optional): Specific assessment period (defaults to latest available per student).
  - `sort_by` (string, optional): Column name (e.g. `latest_score`, `attendance_rate`, `student_id`).
  - `ascending` (bool, optional): Sort order (`true`/`false`).
  - `page` (int, optional, default: 1): Page index.
  - `page_size` (int, optional, default: 20): Results per page.

---

### 4. Single Student Detail & Longitudinal History
- **Method**: `GET`
- **Path**: `/api/students/{student_id}`
- **Response**: Full student trajectory across all periods, historical mean scores, standard deviation, and pedagogical focus areas.

---

### 5. Model Metrics & Evaluation Comparison
- **Method**: `GET`
- **Path**: `/api/model/metrics`
- **Response**: Model comparison matrix, held-out test set confusion matrix, global feature importances, and trade-off analysis.
